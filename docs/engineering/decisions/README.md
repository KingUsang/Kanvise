# Architecture decision records

Use an ADR for decisions affecting system boundaries, authentication, tenancy,
persistent data, public API compatibility, providers, or deployment topology.

Each ADR records context, decision, alternatives, tradeoffs, compatibility,
rollout, consequences, status, owner, and last verification date.
