## Document statuses

- **Draft:** under discussion; not enforceable.
- **Current:** approved source of truth.
- **Superseded:** replaced and linked to its replacement.
- **Historical:** retained as evidence, not current instruction.

The [document authority map](./DOCUMENT_AUTHORITY.md) classifies legacy material.
When documentation and implementation conflict, record the deviation instead
of silently choosing one.
