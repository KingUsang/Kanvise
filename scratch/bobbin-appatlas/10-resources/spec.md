# Resources

Route: `/resources`

The Resources library separates folders from unfiled files and provides search/filtering, a “show files in folders” view, folder creation, and upload.

## Folder flow

**New folder** opens a dialog with a required name and a default-on “Share with everyone” toggle. The copy explains that shared folders appear in the Organization tab inside every LessonSpace. A synthetic shared test folder was submitted and its populated-library state is captured.

## Upload flow

**Upload files** accepts PNG/JPG/PDF/Word/PowerPoint, permits a folder selection and sharing choice, and presents a drag/drop or file-picker surface. A non-sensitive research PNG fixture was selected and uploaded; the selected and completed states are captured.

The admin audit also captures every resource-filter branch: file type (Images/PDFs/Documents), sharing visibility, and uploaded-from/uploaded-to date pickers.
