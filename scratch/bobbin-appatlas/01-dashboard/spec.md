# Admin dashboard

Route: `/`

The administrator landing page combines setup/trial status, onboarding guidance, today's lesson, a weekly schedule, live monitoring, safeguarding/report attention counts, help/sales prompts, and the mobile-recording beta promotion.

The audit captures admin global search (Students, Tutors, Clients, Courses, Lessons, and Settings), account and help menus, and the mobile-app detail dialog. The dashboard's attention cards link into safeguarding, report approvals, and outstanding-report lesson states.
